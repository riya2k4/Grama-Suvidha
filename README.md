# Grama-Suvidha Portal

Grama-Suvidha Portal is an Android application developed using Kotlin and Android Studio to improve transparency in rural infrastructure and government development projects. The app acts as a digital notice board where villagers can track ongoing works, monitor progress, view project details, and report issues.

## Features

- View village development projects
- Track project progress using progress bars
- View project budgets and status updates
- Report issues and give ratings
- Offline support using Room Database
- Kannada and English language support
- RecyclerView-based UI
- Image loading using Glide
- MVVM Architecture
- JSON-based local data integration

## Technologies Used

- Kotlin
- Android Studio
- XML Layouts
- Room Database
- RecyclerView
- LiveData & ViewModel
- Glide
- MVVM Architecture
- JSON Parsing

## Project Objective

The objective of this project is to reduce the transparency gap in rural development projects by allowing citizens to access project information, monitor work progress, and participate in local governance digitally.
